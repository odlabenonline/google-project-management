# google-project-management
Repository to track my progress in Google Project Management on Coursera offered to me by PerScholas

## Goal

Complete the Google Project Management Professional Certificate in **4 months**
at a **10 hours/week** commitment, with a daily study habit.

## How progress is tracked

- [TIMELINE.md](TIMELINE.md) — week-by-week schedule mapping the 4-month plan
  to each course and module, with target dates and hours.
- [ASSIGNMENTS.md](ASSIGNMENTS.md) — checklist of quizzes and peer-reviewed
  assignments for every course, to make sure nothing is missed.
- [DAILY_LOG.md](DAILY_LOG.md) — a daily log of study sessions (date, hours,
  what was covered) so I can commit to the course every day and see my streak.

Workflow: each day, study a bit, add a row to `DAILY_LOG.md`, check off items
in `ASSIGNMENTS.md` as they're completed, and mark weeks done in
`TIMELINE.md` as they wrap up.
