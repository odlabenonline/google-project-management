# Daily Log

A running log of daily study sessions, so I can commit to this course every
day and see my progress at a glance. Add one entry per study day, most recent
first. See [TIMELINE.md](TIMELINE.md) for the weekly plan and
[ASSIGNMENTS.md](ASSIGNMENTS.md) for graded items.

## How to use this file

1. Copy the template row below into the table for each day you study.
2. Fill in the date, hours spent, course/module, and what you did.
3. Commit the update — the commit itself is your daily streak marker.

Template row:

```
| YYYY-MM-DD | 0.0 | Course N: Name | What you studied / did | Notes |
```
